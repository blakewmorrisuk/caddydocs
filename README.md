# caddydocs.com

The public website for **Caddy**, a macOS app that puts a little workstation on the edge of
your screen. Static HTML, one stylesheet, one script, no framework, no third-party requests.

- `/` · the landing page
- `/privacy` · the privacy policy the Mac App Store submission points at
- `/support` · support, and the address that reaches a person

Deployment, the two URLs the app hard-codes, and how the pictures were made:
see [DEPLOY.md](DEPLOY.md).
